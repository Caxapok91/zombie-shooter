# ZOMBIES — браузерная версия

Порт игры на HTML5 Canvas. Работает без сервера и сборки: всё лежит в этой папке,
достаточно открыть `index.html`.

## Запуск локально

- Откройте `docs/index.html` двойным щелчком, **или**
- запустите статический сервер из корня репозитория:

```bash
python -m http.server 8000
# http://127.0.0.1:8000/docs/
```

Сервер нужен только для того, чтобы браузер загрузил кастомные шрифты
(при открытии файла напрямую Chrome может их заблокировать и подставит Impact).

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub.
2. **Settings → Pages → Source: Deploy from a branch**.
3. Ветка **main**, папка **`/docs`**.
4. Игра откроется по адресу `https://<user>.github.io/<repo>/`.

Никаких Actions и сборки не нужно: это обычные статические файлы.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | `WASD` или стрелки |
| Спринт | `Shift` (тратит стамину; полоска под здоровьем) |
| Прицел / фонарик | мышь |
| Выстрел | ЛКМ или `Space` |
| Пауза | `P` или `Esc` |
| Старт | `Enter`, `Space` или кнопка **PLAY** |
| Полный экран | кнопка **FULLSCREEN** |

## Что внутри

```
index.html            страница и <canvas>
style.css             шрифты, фон, масштабирование
js/level.js           данные уровня (стены, спавны), сгенерированы из maps/level1.tmx
js/game.js            вся игра
assets/map.png        карта 3200x1920, отрисована из тайлов TMX
assets/img/*.png      спрайты, кляксы, прицел
assets/snd/**, music  звуки и музыка
assets/fonts/*        ZOMBIE.TTF и Impacted (HUD)
tools/export_assets.py  пересборка assets + level.js из pygame-версии
```

## Отличия от pygame-версии

- Кнопка **QUIT** заменена на **FULLSCREEN** (в браузере вкладку нельзя закрыть скриптом).
- Ночь/фонарик рисуются через canvas-градиенты, но повторяют логику и тайминги.
- Музыка стартует после первого клика/нажатия клавиши — политика автозапуска браузеров.

## Служебные параметры (для проверки)

- `?selftest` — встроенная самопроверка (16 проверок), результат выводится на экран;
- `?play=600` — сразу начать игру и прокрутить 600 кадров симуляции;
- `?night` — начать игру ночью, чтобы посмотреть фонарик;
- `?menu` — открыть настройки на стартовом экране.

## Пересборка ассетов

Если поменялся `maps/level1.tmx` или картинки:

```bash
pip install pygame pytmx
python docs/tools/export_assets.py
```

Скрипт заново отрисует `assets/map.png`, скопирует спрайты/звуки и сгенерирует `js/level.js`.
